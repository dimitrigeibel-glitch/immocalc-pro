2. Welche Daten werden verarbeitet?

A) Hosting-Protokolldaten Cloudflare Pages

Diese Website wird über Cloudflare Pages (Cloudflare, Inc., 101 Townsend St., San Francisco, CA 94107, USA) gehostet. Beim Abruf einer Seite übermittelt dein Browser automatisch:

Der Rechner speichert deine zuletzt eingegebenen Werte im localStorage deines Browsers, damit du beim nächsten Besuch weitermachen kannst. Diese Daten verlassen deinen Browser nie. Du kannst diese Daten jederzeit über die Browser-Einstellungen löschen.
